# LLM 기반 AI 강사 Agent

PPTX 자료를 입력받아 슬라이드별 강의 대본과 음성을 만들고, 강의 영상·핵심 요약·퀴즈를 제공하는 팀 프로젝트입니다.

- 프로젝트 기간: 2026.05.11–2026.05.13
- 팀 구성: 8명
- 김남효 담당: 영상 합성, 결과보고서·발표 PPT 제작, Agent 구조와 서비스 흐름 시각화

## 프로젝트 개요

PPT 자료를 강의 영상으로 만들 때 반복되는 대본 작성, 녹음, 영상 편집 작업을 하나의 흐름으로 연결했습니다. 강의 영상 생성에 더해 핵심 요약과 O/X 퀴즈를 제공하여 학습 내용을 확인할 수 있도록 구성했습니다.

## 팀이 구현한 기능

| 단계 | 구현 내용 |
| --- | --- |
| PPT 분석 | python-pptx로 슬라이드별 제목·텍스트·표·이미지 추출 |
| 검색과 설명문 | 제목·본문을 함께 사용한 Tavily 검색 결과와 슬라이드 원문을 LLM에 전달 |
| 대본 생성 | 현재 슬라이드 설명과 이전 대본을 함께 사용 |
| 음성·영상 | OpenAI TTS로 음성을 생성하고 FFmpeg로 슬라이드 이미지와 합성 |
| 최종 결과 | 슬라이드별 영상 병합, 전체 대본 요약, 요약 기반 O/X 퀴즈 3개와 정답·해설 생성 |
| 사용자 화면 | Gradio에서 PPTX 업로드, 영상 확인·다운로드, 요약·퀴즈 표시 |

LangGraph는 PPT 분석을 한 번 수행한 뒤 검색·설명문·대본·TTS·영상 합성·누적 단계를 슬라이드 수만큼 반복합니다. 마지막 슬라이드 처리 후 영상 병합, 요약, 퀴즈 생성으로 넘어갑니다.

## 나의 역할

영상 합성 담당으로 슬라이드 이미지와 음성을 연결하는 작업에 참여했습니다. 구현은 음성 길이에 맞춰 정지 이미지를 영상으로 만들고, 슬라이드 순서대로 최종 MP4를 병합하는 방식입니다.

결과보고서와 발표 PPT에서는 기능별 입력·출력을 정리하고, 반복 구간과 종료 조건을 포함한 Agent 흐름을 시각화했습니다. 문제 정의부터 영상 생성, 요약·퀴즈 확장까지 이어지는 발표 구성을 맡았습니다.

## 코드와 실행

실행 코드는 `lecture_agent.ipynb`에 있습니다. Google Colab 기준의 환경 설치·입력 업로드·기능 정의·Gradio 실행 셀로 구성됩니다.

1. 노트북을 Colab에서 엽니다.
2. 시스템 도구와 Python 패키지 설치 셀을 실행합니다. LibreOffice, Poppler, FFmpeg와 한글 폰트가 필요합니다.
3. API 설정 셀의 `path`를 본인의 작업 폴더로 변경합니다. 해당 폴더의 `api_key.txt`에 아래 항목을 설정합니다. 실제 키를 저장소에 업로드하지 마세요.

```text
OPENAI_API_KEY=본인의_OpenAI_키
TAVILY_API_KEY=본인의_Tavily_키
```

4. PPTX를 업로드하고 노트북 순서에 따라 실행합니다. 중간 예제 실행 셀도 API를 호출하므로 반복 실행 시 비용이 발생할 수 있습니다.
5. Gradio 실행 셀에서 파일·대본 작성 톤·음성을 선택하고 결과를 확인합니다.

저장소의 `sample1.pptx`, `sample2.pptx`는 입력 예시이며, 대표 강의 결과물은 `결과영상.mp4`입니다. `sample.mp4`는 별도의 실습용 영상입니다. 실행 환경의 API 응답과 변환 프로그램에 따라 새 결과는 달라질 수 있습니다.

기존 `Step2_조별과제_AI 강사 Agent v2.2.ipynb`는 작업 흐름을 참고할 수 있도록 보존하며, 키 출력과 저장된 실행 결과만 정리했습니다. 실행과 테스트에는 `lecture_agent.ipynb`를 사용하세요.

### 키 없는 테스트

```bash
python -m pip install -r requirements-test.txt
python -m pytest test_lecture_agent.py -q
```

테스트는 노트북의 함수 정의를 읽어 검사합니다. 실제 LangGraph의 상태 전달·반복과 FFmpeg 합성을 확인하며, 외부 API는 테스트 응답으로 대체합니다. 전체 유료 API 연동·생성 품질 검증과는 구분됩니다.

### 생성 결과 검증

키 없는 테스트 **38개**와 `sample2.pptx` **3장 전체의 실제 API 통합 실행**을 완료했습니다. PPT 변환부터 최종 영상·요약·퀴즈까지 생성했으며, 결과 영상은 **1920×1080, 약 3분 49초**입니다. 슬라이드별 음성·영상 길이 일치와 최종 영상 전체 디코딩도 확인했습니다. [실행 조건과 점검 결과](INTEGRATION_CHECK.md)

검색 자료는 슬라이드 원문을 보충하는 용도로 사용하고, 대본과 요약에도 원문을 함께 전달합니다. 단계별 출력 한도와 종료 사유를 확인하며, 길이 제한으로 중단되거나 내용이 비어 있으면 다음 단계로 넘기지 않습니다.

퀴즈는 문제·O/X 정답·해설을 포함한 JSON으로 생성합니다. 문제 3개, 필수 항목, 중복 여부를 검증한 뒤 코드에서 정답·해설 접기 화면을 만듭니다. 이 검증은 형식과 완결성에 대한 검사이며, 내용의 사실성이나 학습 효과를 보장하지는 않습니다.

## 한계와 향후 개선

- 퀴즈는 학습자가 정답·해설을 확인하는 방식입니다. 답안 제출·자동 채점·개인별 이해도 측정은 향후 확장 범위입니다.
- 검색 결과와 생성 대본은 사람의 검토가 필요합니다. 프롬프트의 60–90초 지시는 실제 음성 길이를 보장하지 않습니다.
- 설명문 생성에는 첫 표의 최대 6행과 이미지 최대 2개를 사용합니다. 복잡한 PPT와 그룹 도형, 폰트에 따른 변환 품질을 추가 점검할 필요가 있습니다.
- 자막 생성, 대본 승인 후 TTS 실행, 단계별 재시도와 품질 평가를 보완할 수 있습니다.
- 제작 시간·비용 절감과 학습 효과는 실제 사용자 실험으로 측정할 후속 과제입니다.
